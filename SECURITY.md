# Security policy

This policy applies to every N2JSoft repository that does not have its own `SECURITY.md`.

## Reporting a vulnerability

**Do not open a public issue, discussion or pull request for a vulnerability.**

Report it through GitHub private vulnerability reporting: open the affected repository's
**Security** tab and click **Report a vulnerability**. Only the maintainers can read the report.

Please include:

- what an attacker can do, and what they need first;
- the steps to reproduce, with the version of the tool and your OS;
- logs or output that help, with account ids, hostnames and other private data removed.

## What happens next

- We acknowledge the report within **3 business days**.
- We send a first assessment (confirmed or not, severity, planned fix) within **10 business days**.
- We fix confirmed vulnerabilities in a new release, then publish a GitHub security advisory that
  credits you, unless you prefer to stay anonymous. Please keep the details private until then.

## Supported versions

Only the **latest release** of each project gets security fixes.
