# Getting help

- **Something does not work as documented**: open an issue in the project's repository, with the
  version you run, your OS and the steps to reproduce.
- **A question or an idea**: open an issue too; we answer there so that others can find it.
- **A security vulnerability**: never in a public issue. See [SECURITY.md](SECURITY.md).

These projects are maintained by the N2F engineering team on a best-effort basis: there is no
guaranteed response time outside security reports.
